# AI Clinical Safety & Guardrails Architecture

This document specifies the strict safety policies, anti-prompt-injection defenses, structured JSON schemas, and architectural boundaries governing LLM usage on the DocPulse Healthcare Platform.

---

## 1. Absolute Medical AI Guardrail Rules

1. **NO Medical Diagnoses**: The AI assistant is forbidden from stating definitive diagnostic conclusions.
2. **NO Drug Prescriptions**: The AI assistant never prescribes, names specific drug therapies, or recommends dosage adjustments.
3. **NO Replacement of Human Doctors**: The AI exists strictly to organize patient-reported intake details and assist patients in discovering relevant medical specialties.
4. **Backend-Only API Key Execution**: AI API keys (`GEMINI_API_KEY`) are kept exclusively on the server and never exposed to the client bundle.
5. **Universal Medical Disclaimer**: Every AI-generated summary and recommendation unconditionally includes a safety notice.

---

## 2. Defensive Processing Pipeline

```text
User Natural Language Input
       │
       ▼
1. Anti-Prompt-Injection Sanitization (`server/services/aiService.js`)
   - Strips overrides: "ignore previous instructions", "act as a doctor and prescribe", etc.
   - Caps input length to 1000 characters.
       │
       ▼
2. System Instruction Grounding (`server/config/ai.config.js`)
   - Forces strict clinical boundaries and structured JSON response formatting.
       │
       ▼
3. LLM Generation (Google Gemini / Safe Fallback Engine)
       │
       ▼
4. Post-Generation Output Sanitization
   - Validates JSON schema against forbidden diagnosis patterns.
   - Attaches universal safety disclaimer.
       │
       ▼
Structured Response Envelope Sent to Frontend
```

## 3. Structured JSON Schemas

### Feature 1: Patient Intake Summary Schema
```json
{
  "healthConcern": "Patient stated symptoms in neutral terminology",
  "duration": "Reported duration",
  "historySummary": "Summarized relevant past conditions",
  "questionsForDoctor": [
    "Suggested question for the patient to ask the physician",
    "Diagnostic or evaluation question"
  ],
  "safetyNotice": "This summary is organized by AI for communication assistance only. It is NOT a medical diagnosis and does NOT replace consultation with a licensed doctor."
}
```

### Feature 2: Doctor Search Assistant Schema
```json
{
  "query": "Symptoms description",
  "city": "Location",
  "primarySpecialization": "Cardiology",
  "recommendedSpecializations": ["Cardiology", "General Medicine"],
  "searchKeywords": ["Cardiology", "chest", "heart"],
  "guidance": "Recommended clinical specialty to consult",
  "safetyDisclaimer": "This search recommendation is generated by AI to help discover doctors. It is NOT a clinical diagnosis."
}
```
